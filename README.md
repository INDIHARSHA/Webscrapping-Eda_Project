# Webscrapping-Eda_Project
# 🕸️ Web Scraping Project

This repository contains scripts and notebooks for extracting, cleaning, and analyzing data from websites using Python.

## 📌 Project Overview
Web scraping is used to collect structured data from web pages.  
This project demonstrates:
- Sending HTTP requests to websites
- Parsing HTML content
- Extracting specific information (titles, links, tables, etc.)
- Saving the scraped data into CSV/JSON formats
- Handling dynamic content and pagination

## ⚙️ Tools & Libraries
- **Python 3.x**
- **Requests** → for sending HTTP requests
- **BeautifulSoup (bs4)** → for parsing HTML
- **Pandas** → for organizing and saving data
